# Agent Workspace UI/UX audit, November 3, 2026

This audit covers the working tree of `codex/ux-repair` (0.4.1), including its uncommitted edits.

**Method.**
- **Code review.** Three separate reviewers each read one part of the renderer line by line: all 17.6k lines across 42 files, plus the main-process window code.
- **Live tour.** The built Electron app was driven with fixture providers. Screenshots and an automated scan (accessible names, labels, computed text contrast, target sizes, overflow, tab order) covered 35 desktop states.
- **Phone tour.** The headless host was opened in mobile Chromium (390×844, landscape, 320px). It covered 11 states.
- **Pattern detector.** The Impeccable design detector ran over `src/renderer`.

Findings marked **runtime** were seen in the running app. Everything else was confirmed in source, with a `file:line` reference.

**Not covered:** VoiceOver, physical phones, real SSH hosts or team servers, live model turns, and Windows/Linux.

Evidence screenshots: [screenshots/ux-audit-2026-11-03](screenshots/ux-audit-2026-11-03).

## Verdict

The product has a clear point of view: a calm dark tool with honest copy ("Nothing is sent until you type", "a line never starts work automatically"). Safety is designed well:
- preview before anything is shared;
- explicit consent;
- SSH host-key handling that never trusts a key for you;
- bracketed paste that never auto-submits.

The weaknesses come from the space between features. The keyboard and focus model breaks wherever a terminal, a `<details>` element or a nested dialog appears. Errors from inside dialogs land in a banner the dialog hides. Several "silent state" problems mean the app does something different from what it shows: a remembered worktree, a hidden first message, a stale Changes list, and editor drafts dropped on navigation.

The phone experience works but gives most of the screen to chrome. Pairing it is hard. The Nov 1 repairs (F04, F06, F07, F11, F12) are real, but each one is incomplete in a way listed below.

## P2: fix in the next pass

### Keyboard and focus
- **Rename "Suggest name" can't be reached by keyboard.** Blur closes the rename row before Tab lands on the button (`SessionView.tsx:194,205-216`).
- **Popups marked `role="menu"` don't behave like menus.**
  - Canvas card **Actions** doesn't close on Escape or an outside click; in the tour it stayed open behind the Connect dialog.
  - The pane menu, Folder actions, Lane/Move menus and Launch options have no arrow keys and don't return focus (`CanvasView.tsx:227-266,885-913`, `App.tsx:1032-1073`, `LaunchBar.tsx:91-93`). Runtime.
- **Moving a canvas card with the arrow keys isn't saved or undoable.** Only the drag handlers save (`CanvasView.tsx:854-859`).
- **⌘K and ⌘N replace an open Task or Attempt form and lose its text.** The palette also opens underneath dialogs rendered into `body` (`App.tsx:650-664`, `modal-accessibility.ts:26-31`).
- **Swapping views inside a dialog drops focus to `<body>`.** This happens in the SSH host list/browser, Team list/project, comment edit and the Transcript Connect step.
- **The command palette has no combobox/listbox semantics,** and the active item can scroll out of view (`App.tsx:2051-2086`).

### Screen-reader semantics
- **The selected folder, session, view and places entry aren't exposed:** there is no `aria-current` (`App.tsx:703-712,789-798,1400-1442`, `FolderBrowser.tsx:170-173`).
- **"Needs you" and status are conveyed by colour only.** The dots have no text, and Turn failed and Needs you are both amber (`App.tsx:816-818,948,1398`, `ui.tsx:38-39`).
- **Status changes on the open session aren't announced.** Panel status messages are inserted already filled, so screen readers may skip them (`SessionView.tsx:235`, SSH/Remote/Profiles/Transcript/Team).
- **The dictation timer sits inside a live region,** so it is announced every 500 ms (`DictationControl.tsx:66-80`).
- **The task card "Move" handle is a focusable button that does nothing.** Its visible text doesn't match its accessible name (`Board.tsx:138-149`).
- **The Review "W" button's accessible name is just "W"** (`ReviewPanel.tsx:356-362`).
- **The Remote access mode radios sit inside the "1. Choose folders" fieldset** (`RemoteAccessPanel.tsx:126-152`).
- **`aria-label` hides content or sits where it is ignored.** Shared task buttons lose their status and assignee, and the comment count is read as just "3" (`TeamPanel.tsx:648,663-666`, `TaskTeam.tsx:49`).
- **Toasts may not be announced** (the live region is inserted together with its content) and they vanish after 9 s with no pause (WCAG 2.2.1) (`App.tsx:377,1444-1450`).
- **Important reasons live only in `title` tooltips:** disabled launch buttons, Keep awake, "Set up", and Enable recipient reading (`LaunchBar.tsx:185-191`, `App.tsx:1504-1508`).
- **The terminal's grey (`brightBlack #5c6577`) is 3.25:1,** and agents use it for hints (`TerminalView.tsx:261`).

### Status, feedback and errors

- **Panel errors appear far from their cause.** They sit at the bottom of long SSH, Remote and Team dialogs, and the Remote port error refers to a field inside a collapsed `<details>`.
- **Primary buttons are disabled with no visible reason** (Remote Enable, Transcript Connect whose consent box is placed after the button, SSH Add, Create task, Profiles Set up). Runtime.
- **Swallowed failures leave endless "Loading…" or false empty states:** Team status, shared tasks, TaskTeam chips, Remote status, and Agent control (`TeamPanel.tsx:31-34,482-485`, `TaskTeam.tsx:30`, `AgentControl.tsx:59-66`).
- **A success message is shown as an error.** Profiles "Removed…" appears in the red `role="alert"` box (`ProfilesPanel.tsx:284-287`).
- **Pairing errors blame the code for every failure,** including 403 origin, 5xx and network errors; a network failure shows "Failed to fetch" (`remote.ts:101-106`, `BrowserRoot.tsx:56-59`).
- **With tmux missing, Claude and Codex look available, then fail.** The notice offers "Try again" and "Check again", but tmux is only resolved at core startup, so neither can work (`sessions.ts:128-131`, `core/index.ts:166,943`).
- **Settings & connections is empty in remote browsers;** every item is gated off (`App.tsx:930-936,1501-1610`).
- **The first remote load flashes "No folders are shared…" and "Reconnecting"** before the first snapshot arrives (`App.tsx:300-305,696-699`).
- **The Changes panel never refreshes on its own.** After an agent edits files it keeps saying "Working tree is clean" until you press Refresh (`ReviewPanel.tsx:188-190`).
- **Branching from the Board live card gives no feedback:** `onOpen` isn't passed (`SessionBoard.tsx:680-689`).
- **The Team browser sign-in can't be cancelled.** Every Team button stays disabled for up to 5 minutes (`TeamPanel.tsx:239-241`).
- **Remote access shows no paired devices and no core health.** "Listener running" is shown even when the core has failed (`RemoteAccessPanel.tsx:117,293-351`).

**Theming and integrity**
